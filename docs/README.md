# Documentacion

- `architecture/`: decisiones y mapas de componentes.
- `operations/`: procedimientos de Supabase, Vercel y administracion.
- `audits/`: resultados de seguridad, espacios fisicos y remediaciones.
- `audits/data/`: inventarios y archivos fuente asociados a auditorias.
- `archive/`: documentos historicos que no describen el runtime actual.

`TEST_COVERAGE_MATRIX_20260809.md` registra la cobertura vigente y
`PROJECT_FILE_MATRIX_20260809.csv` es un inventario regenerable mediante `npm.cmd run inventory`.
